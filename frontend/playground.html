Cynex playground: break it yourself

Every settle here is a real transaction against the live vault, signed by the agent key on the executor host. A wrong payee or amount is rejected on chain with a reason code and a transaction hash. Nothing here is simulated. The executor token authenticates you to the executor; the agent key never leaves the executor host and the owner key is never here.

Receipts: tamper-and-detect


The live receipt chain, read from the selected vault. Edit one amount in a local copy and verify it: the chain check recomputes every prev_hash link with the frozen receipt hash formula, in your browser. The tampered copy is local only; the live chain is never modified. A tamper is detected at the receipt after the tampered one; the last receipt has no next row yet, so it is only anchored when the next receipt arrives.
